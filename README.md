# Skincare Customer Sentiment and Review Theme Analysis

## Project Overview

This project analyses customer reviews of skincare products using Python. It aims to understand customer satisfaction, ratings, and feedback through exploratory data analysis and data preprocessing.

**Status:** Updated prototype using a real Sephora customer review dataset.

## Business Problem

Star ratings show how customers rate skincare products, but they do not fully explain why customers like or dislike them. This project explores ratings and written reviews to identify customer opinions, satisfaction levels, and common feedback patterns.

## Research Questions

1. What is the distribution of customer ratings?
2. Which brands receive the most reviews?
3. What are the most common words in customer reviews?
4. What proportion of reviews are positive, neutral, and negative based on ratings?
5. What patterns can be identified from customer feedback?

## Dataset

The project uses a 10,000-review sample from the [Sephora Products and Skincare Reviews dataset](https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews).

**Dataset file:** `sephora_skincare_reviews_sample.csv`

The sample contains 10,000 records and 18 columns.

### Important Features

- `review_text`: Written customer feedback
- `rating`: Product rating
- `is_recommended`: Recommendation status
- `submission_time`: Review date
- `skin_type`: Customer skin type
- `product_name`: Product name
- `brand_name`: Brand name

## Sentiment Classification

Sentiment is initially classified using customer ratings:

- **4–5 stars:** Positive
- **3 stars:** Neutral
- **1–2 stars:** Negative

These are rating-based sentiment labels, not predictions from an AI text classifier. The actual meaning of written reviews may differ from their star ratings.

## Week 3: Data Cleaning and Preprocessing

A separate preprocessing pipeline has been introduced to prepare the Sephora review dataset for further analysis.

### Cleaning Operations

- Checks missing values in the dataset.
- Handles missing customer profile information by assigning an `Unknown` category.
- Converts relevant numeric columns into numeric format.
- Identifies invalid rating values and negative numeric values.
- Standardizes review text while preserving the original review text.
- Parses review submission dates.
- Removes exact duplicate rows.
- Creates rating-based sentiment labels.
- Generates a cleaning summary.

### New Files

- `data_cleaning.py` – Python script for data cleaning and preprocessing.
- `sephora_skincare_reviews_cleaned.csv` – Cleaned dataset generated by the pipeline.
- `cleaning_summary.csv` – Summary of missing values and cleaning operations.

**Note:** The preprocessing script removes exact duplicate rows. This is different from removing records based only on repeated review text.

## How to Run

### 1. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 2. Run Exploratory Data Analysis

```bash
python analysis.py
```

### 3. Run Data Cleaning and Preprocessing

```bash
python data_cleaning.py
```

The preprocessing script generates:

- `sephora_skincare_reviews_cleaned.csv`
- `cleaning_summary.csv`

Make sure the original sample dataset is present in the project folder before running the scripts.

## Limitations and Ethics

- The analysis uses a 10,000-review sample, not the complete dataset.
- The sample is a convenience sample and may not represent all Sephora customers.
- Rating-based sentiment may not always match the actual meaning of review text.
- Customer reviews may contain personal opinions and biases.
- Reviews are opinions and not clinical evidence of product safety or effectiveness.
- Dataset usage must follow its applicable licence and terms.
